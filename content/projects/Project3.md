## Project Overview

This project presents a comprehensive analysis of the **IMDb Dataset**, which contains detailed information about movies, TV shows, and other forms of visual entertainment, along with ratings contributed by the online community. Each record includes key attributes such as the original title, release year, runtime, user votes, awards, nominations, user reviews, critic ratings, and metadata like country of origin and genre. The dataset is current as of September 1, 2024.

Our goal was to explore and analyze the dataset using various data mining and machine learning techniques, including:

- Data understanding and preprocessing  
- Clustering (DBSCAN, K-Means, Hierarchical Clustering)  
- Classification (K-Nearest Neighbors, Naive Bayes, Decision Trees)  
- Pattern mining (FP-Growth, Apriori)  
- Regression analysis  

---

## Methodology and Tasks

1. **Data Understanding and Preparation**  
   We began by exploring the dataset to assess data quality, identify missing values, and perform necessary cleaning and transformation.

2. **Clustering**  
   Applied clustering algorithms to group similar titles based on features like genre, ratings, runtime, and other metadata.

3. **Classification**  
   Built supervised models to predict categories or characteristics of movies and shows, such as genre or popularity.

4. **Pattern Mining**  
   Employed association rule mining techniques to uncover frequent patterns and relationships between awards, ratings, genres, and other variables.

5. **Regression Analysis**  
   Used regression models to analyze and predict trends in ratings and user engagement over time.
